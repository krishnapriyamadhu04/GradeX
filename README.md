# GradeX — Performance & CGPA Predictor

**GradeX** is a beginner-friendly Machine Learning project that predicts a
college student's **Current Semester CGPA** (0–10) based on their internal exam,
assignment, lab/practical scores, attendance, and previous semester CGPA.

> **Disclaimer:** This project uses entirely **synthetic / generated data** for
> machine learning demonstration purposes. It does **not** represent real student records, and the ML prediction is **not** the real calculation formula.

---

## Project Objective

Build a supervised regression ML pipeline that accepts five academic inputs and
predicts a student's current semester CGPA on a 0–10 scale, using Linear
Regression as a baseline and Random Forest Regressor as the main model.

---

## Input Features

| Feature | Description | Maximum Marks |
|---|---|---|
| `internal_exam` | Internal Examination Score | 50 |
| `assignment` | Assignment Score | 15 |
| `lab_practical` | Lab / Practical Examination Score | 100 |
| `attendance` | Attendance Marks | 10 |
| `previous_semester_cgpa` | CGPA secured in the previous semester | 10 |

**Prediction target:** `current_semester_cgpa` — Current Semester CGPA (0–10)

---

## Machine Learning Approach

| Model | Type | Role |
|---|---|---|
| Linear Regression | Baseline | Simple, interpretable linear model |
| Random Forest Regressor | Main model | Ensemble of decision trees, more accurate |

### Evaluation Metrics (Regression)

| Metric | Description |
|---|---|
| **R² Score** | How well the model explains variance in CGPA. 1.0 = perfect. |
| **MAE** | Mean Absolute Error — average error in CGPA units. Lower is better. |
| **RMSE** | Root Mean Squared Error — penalises large errors more than MAE. |

> These are **regression metrics**, not classification accuracy.

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. (Optional) Regenerate the dataset

```bash
python data/generate_data.py
```

### 3. Train the models

```bash
python train_model.py
```

This will:
- Load and preprocess `data/student_scores.csv`
- Train both models and print R², MAE, and RMSE on the test set
- Save models and scaler to `models/`
- Save an Actual vs Predicted plot to `models/actual_vs_predicted.png`

### 4. Launch the Streamlit app

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.
